### 遊戲伺服器開發 / Game server development

專注在線上遊戲的伺服器端：封包協定、遊戲邏輯、經濟系統，以及營運用的管理工具。

I work on the server side of online games: network protocols, game logic, in-game economies and the tools that keep a live server running.

**擅長 / Focus**

- 伺服器架構：連線管理、頻道與地圖分流、排程與資料存檔
- 封包協定：解析、設計與相容舊版客戶端
- 遊戲系統：任務、副本、交易、小遊戲與活動
- 營運工具：GM 主控台、機器人、監控與自動更新
- 資料庫：MySQL／SQL Server 結構設計、備份與效能調整

**常用技術 / Stack**

Java · C++ · C# · MySQL · SQL Server · Netty · Windows Server
